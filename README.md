# 자막 메모장 (notepad)

vtt / srt / lrc / txt 파일을 눌러서 바로 열고 고치는 아주 단순한 메모장.
외부 네트워크 없음, 저장소 권한 없음. 줄바꿈(CRLF/LF)과 인코딩(UTF-8/UTF-16/한글 옛 인코딩)은 원본 그대로 유지해서 저장한다.

- 상단: 왼쪽에 파일 열기, 가운데 파일 이름(수정되면 `*`)
- 하단 도구줄: 뒤로 / 앞으로 / 새로고침 / 검색 / 전체 선택 / 저장 / 다른 이름으로 저장. 키보드가 올라오면 키보드 바로 위에 붙는다. 새로고침은 파일이 없으면, 뒤로·앞으로는 기록이 없으면 흐리게 꺼진다
- 뒤로/앞으로: 하드웨어 키보드의 Ctrl+Z / Ctrl+Shift+Z(Ctrl+Y) 와 같은 기록을 쓴다. 이어서 입력한 글자는 단어 단위로 묶이고(한글 조합 포함), 모두 바꾸기는 한 번에 되돌린다. 바뀐 부분만 저장해서 긴 글에서도 가볍다. 새 파일을 열거나 다시 불러오면 기록이 비워진다. 되돌려서 저장한 상태와 같아져도 제목의 `*`는 저장할 때까지 남는다
- 검색: 대소문자 구분 없이 모든 결과를 칠해 주고, ▲▼ 또는 키보드의 검색 키로 이동. 글자를 선택하고 검색을 누르면 그 글자로 바로 검색
- 바꾸기: 검색창 왼쪽의 바꾸기 아이콘을 누르면 바꿀 내용 입력줄이 열림. [바꾸기]는 선택된 결과를 바꾸고 다음 결과로 이동, [모두 바꾸기]는 확인 후 전부 바꿈(바꿀 내용을 비우면 삭제)
- 오른쪽 스크롤바: 문서가 길 때 나타나며, 막대를 잡고 끌면 빠르게 이동
- 붙여넣기 후 커서(붙여넣은 글의 끝)가 화면 밖이면 자동으로 그 위치로 스크롤
- 다른 앱에서 파일을 고치고 돌아오면(내용 지문 비교) 제목 앞에 `*` 가 붙고 "불러올까요?" 확인창이 뜬다. 상단의 새로고침 버튼으로 언제든 다시 불러올 수 있고, 보던 위치는 유지된다
- 파일 연결: .txt .vtt .srt .lrc 만 받는다 (확장자는 대문자 포함, 파일 앱이 붙여 주는 종류 이름도 함께 등록)
- 파일 앱에서 눌러 열면 쓰기 권한이 없는 경우가 있다(안드로이드 정책상 앱이 스스로 올릴 수 없음): 이때 저장하면 안내 문구 없이 "다른 이름으로 저장" 창이 열린다. 앱 안의 "열기"로 연 파일은 그대로 덮어쓰기 저장된다
- 편집창은 안드로이드 기본 EditText(NotepadEditText) 를 쓴다: 긴 글에서도 고친 문단만 다시 배치해서 빠르고, 키보드가 올라올 때 커서 위치를 유지한다
- 빌드: GitHub Actions(Build APK) → app-debug.apk

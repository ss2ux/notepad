# 자막 메모장 (notepad)

vtt / srt / lrc / txt 파일을 눌러서 바로 열고 고치는 아주 단순한 메모장.
외부 네트워크 없음, 저장소 권한 없음. 줄바꿈(CRLF/LF)과 인코딩(UTF-8/UTF-16/한글 옛 인코딩)은 원본 그대로 유지해서 저장한다.

- 상단 오른쪽: 검색 / 전체 선택 / 저장 / 다른 이름으로 저장, 왼쪽: 파일 열기
- 검색: 대소문자 구분 없이 모든 결과를 칠해 주고, ▲▼ 또는 키보드의 검색 키로 이동. 글자를 선택하고 검색을 누르면 그 글자로 바로 검색
- 바꾸기: 검색창 왼쪽의 바꾸기 아이콘을 누르면 바꿀 내용 입력줄이 열림. [바꾸기]는 선택된 결과를 바꾸고 다음 결과로 이동, [모두 바꾸기]는 확인 후 전부 바꿈(바꿀 내용을 비우면 삭제)
- 오른쪽 스크롤바: 문서가 길 때 나타나며, 막대를 잡고 끌면 빠르게 이동
- 붙여넣기 후 커서(붙여넣은 글의 끝)가 화면 밖이면 자동으로 그 위치로 스크롤
- 편집창은 안드로이드 기본 EditText(NotepadEditText) 를 쓴다: 긴 글에서도 고친 문단만 다시 배치해서 빠르고, 키보드가 올라올 때 커서 위치를 유지한다
- 빌드: GitHub Actions(Build APK) → app-debug.apk
